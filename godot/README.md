# Alvine le Chat — prototype Godot

Projet Godot 4 (édition Standard, pas .NET).

## Ouvrir
1. Télécharger le dépôt GitHub.
2. Dans Godot, cliquer sur **Importer**.
3. Choisir le fichier `godot/project.godot` dans le dossier téléchargé.
4. Cliquer sur **Importer et éditer**, puis sur ▶ **Lancer le projet**.

## Commandes
- Flèches gauche/droite ou A/D : marcher
- Espace, flèche haut ou W : sauter
- Échap : fermer le jeu (commande habituelle de la fenêtre)

Le chat dessiné dans cette première version est un personnage provisoire en pixel art généré par code. Il sert à tester les déplacements, les collisions et la caméra ; il sera remplacé par les sprites définitifs d'Alvine à partir de l'image de référence.
